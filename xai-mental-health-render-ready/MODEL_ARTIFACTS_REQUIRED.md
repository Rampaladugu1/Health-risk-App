# Model artifacts required before live prediction

The uploaded notebook contains the code that creates the trained artifacts, but the binary model files are not embedded in `.ipynb`. Before the Render API can perform predictions, place these files in `backend/`:

- `preprocessor.joblib`
- `best_model.joblib`
- `xgboost_model.joblib`
- `processed_feature_names.csv`

They are generated by the training pipeline in `notebooks/chow.ipynb`. Do not commit PHI or other sensitive data.
